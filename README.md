# 创世纪：小小人生

《创世纪：小小人生》（Genesis: Little Lives）是一款离线运行的上帝模拟器原型。当前项目处于第一阶段，重点验证：玩家离开后世界仍会继续，以及每位族人都有自己的生活状态。

## 运行

使用 Godot 4.x 打开此目录中的 `project.godot`，然后运行主场景。项目仅使用 Godot 内置绘图能力，不需要联网或额外素材。

## 当前功能

- 程序绘制的斜视森林、河流、营地和 20 位不同族人。
- 地图有 12 处可见浆果丛，每处有独立库存；耗尽后每 24 个模拟日自然恢复一份。
- 河流是可识别的水域，不能穿越；族人会寻路到河岸格再饮水。
- 族人独立拥有年龄、性格倾向、需求、愿望、位置和当前行动。
- 每位族人有稳定的好奇、外向、勇气、谨慎、独立、耐心六项人格数值；旧存档会按人物 ID 补齐数值，已有数值会保留。
- 饥饿或口渴达到阈值时，族人寻找可到达的浆果丛或河岸，移动到位并完成采食/饮水后才恢复需求。
- 资源耗尽或路径失效会取消目标并进入短暂的探索重试，不会凭空恢复需求。
- 非紧急行动由 Utility AI 综合需求、人格、目标、社交距离、疲劳、资源距离和探索风险打分，再按效用进行加权选择。
- 好奇与外向影响探索/社交倾向；勇气与谨慎改变远处探索风险权重；独立性偏向独自探索并降低求助/社交倾向；耐心提高等待与持续行动时长。
- 人物档案显示六项人格、需求和最近一次效用决策；调试记录包含候选评分与选择理由。
- 疲劳、探索、交谈、人物选择、跟踪、时间控制和存档仍可使用。
- 点击地图人物查看状态；跟踪所选人物。
- 暂停、1×、5×、20×时间控制；空格暂停；滚轮缩放、中键拖动。
- 每 30 秒自动保存，也可手动保存；重新打开时按离线秒数推进世界。
- 存档位于 Godot 用户数据目录中的 `world.json`。

## 当前范围与限制

这是第一阶段的可运行原型，不包含关系、记忆、家庭、生育和季节系统。画面为程序绘制的像素感占位图形，不是最终美术。寻路使用四方向网格，河流与地图上的山石格不可通行；浆果资源库存和再生计时会写入世界存档。人物存档中的进行中采集/饮水路线会在重新载入后重置，并重新决策。

## 当前检查点：0.3 人格效用 AI

第三轮已完成：六项稳定人格数值参与 Utility AI 行动评分；20 位初始人物具备不同人格组合；人物档案和日志可查看决策解释。固定随机种子的对照实验验证了好奇、外向、勇气/谨慎、独立和耐心会改变行动倾向，严重饥饿仍优先触发食物生存流程。详细结果见 `DEVELOPMENT_LOG.md`。

当前已知限制：风险由离营地距离和地图边缘近似，没有动态危险或伤害后果；求助尚无同伴响应；画面为程序绘制的占位美术。项目仍不包含关系、家庭、生育或季节系统。
